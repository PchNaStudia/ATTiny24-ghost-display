Rotating LED display

Live writes from the real firmware main.cpp through a host HAL. Green: first strip; amber: second strip.

Persistence-of-vision view

Unwrapped output (128 × 8)

At the sensor pulse, the primary strip points horizontally left and the secondary points right (180° apart). PA0 is innermost; PA7 is outermost on both strips. Default rotation is clockwise; orientation controls are optional overrides. Unwrapped rows show PA7 at the top and PA0 at the bottom. Geometry, brightness and persistence are illustrative—not an optical simulation. RPM changes the rotation sensor events delivered to the C++ controller.
