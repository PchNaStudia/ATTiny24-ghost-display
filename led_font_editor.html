▦ 8px LED Font Editor

Choose a font, generate readable 8-row capitals, touch up pixels, export one C++ header.

1 · Choose symbols and font

Every character here can be used directly in displayed text. Duplicates are removed automatically.
Referenced as \{0}\, \{1}\, etc. To show a backslash, include \ as a special glyph.
How fitting works

The editor samples uppercase cap-height, scales each glyph automatically into all 8 rows (top-aligned). No baseline, threshold, or size knobs. Symbols with tails are cropped to the cap-height area.

2 · Edit glyphs

Click or drag to draw/erase. Top pixel = bit 0.
Changes are reflected in the preview and export.

4 · Export C++ header
Includes availableSymbols, column bitmap bytes, special glyph indexes, and drawText(). Format: one byte per column, least-significant bit = top pixel. Rendering mode is selected at runtime.
Example C++ use
ledfont::drawText("HELLO \\{0}\\", 0, 0,
  [](int x, int y, bool on) {
    // set LED at x,y
  }, ledfont::RenderMode::Proportional);
In C++ source, backslashes must be doubled. "\\\\" displays a literal backslash if it is included as a glyph.
